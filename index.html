FAQ the ten codes everyone meets

What does S0C7 mean?

A decimal arithmetic instruction encountered invalid packed-decimal or zoned-decimal data. Fix: Use NUMERIC test on COMP-3 inputs before arithmetic, or initialize fields to zero. Check the dump for failing instruction (AP, ZAP, CP, etc.) and the contents of the operands. Full entry for S0C7

What does S0C4 mean?

The program attempted to access storage it is not authorized to read or write. Fix: Look at the PSW and failing instruction in the IPCS dump. Trace the pointer back to where it was set. Full entry for S0C4

What does S806 mean?

The system could not find the requested load module in any library on the search order. Fix: Verify the load module exists with the correct name and that the JCL points to the right STEPLIB. Check link-edit JCL for the correct member name. Full entry for S806

What does SQLCODE -805 mean?

The DBRM or package name was not found in the plan. Fix: BIND PACKAGE for the program. Check CURRENT PACKAGESET and plan PKLIST. Verify collection ID matches. Full entry for -805

What does SQLCODE -811 mean?

The result of an embedded SELECT INTO or scalar subquery is more than one row. Fix: Use a cursor (DECLARE/OPEN/FETCH) for multi-row results. Or refine the WHERE clause with a unique key. Full entry for -811

What does SQLCODE -818 mean?

The precompiler-generated timestamp X in the load module is different from the bind timestamp Y in the DBRM. Fix: Precompile, compile, link, AND bind together. Always rebind after precompiling. Full entry for -818

What does SQLCODE -904 mean?

Unsuccessful execution caused by an unavailable resource. Fix: Check the reason code and resource name in the message. Run COPY, RECOVER, START DATABASE, or similar to recover. Full entry for -904

What does SQLCODE -911 mean?

The current unit of work was rolled back because of a deadlock or timeout. Fix: Application must restart the unit of work. Use LOCK TIMEOUT bind option. Reduce hold time by COMMITting more frequently. Full entry for -911

What does SQLCODE +100 mean?

No row was found that satisfies the search condition, or the result of a FETCH was past the last row of the cursor result table. Fix: Check WHERE clause logic. Treat +100 as a normal end-of-data condition for cursor loops. Always test SQLCODE = 100 after fetches. Full entry for +100

What does ASRA mean?

CICS detected a program check (S0Cx-style) in an application program. Fix: Read the CICS transaction dump for the actual program-check type (often S0C7) and trace it like a batch S0C7. Full entry for ASRA
