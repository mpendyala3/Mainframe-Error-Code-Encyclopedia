MAINFRAME.ENC.BATCH(IEF212I)

IEF212I DATA SET NOT FOUND

  • E · ERROR
  • JCL
  • Job Control and Batch
Explanation
The data set named on a DD statement could not be found in the catalog.
Likely cause
Misspelled DSN, missing catalog entry, or data set was uncataloged or deleted.
Programmer response
Verify the DSN spelling and ensure the data set exists with LISTC ENT(...).
Example
//INPUT DD DSN=MY.NONEXIST.FILE,DISP=SHR
IEF212I JOB1 STEP1 INPUT - DATA SET NOT FOUND
