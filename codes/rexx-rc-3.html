MAINFRAME.ENC.TSO(REXX RC -3)

REXX RC -3 REXX SUBCOMMAND FAILURE

  • E · ERROR
  • REXX
  • Interactive Tools and Scripting
Explanation
Host command environment failed to find or process a subcommand.
Likely cause
ADDRESS environment doesn't support the command, or command misspelled.
Programmer response
Verify ADDRESS environment (TSO, ISPEXEC, SYSCALL, ISREDIT, etc.).
Example
ADDRESS TSO
  'BADCOMMAND'
  /* RC = -3 */
