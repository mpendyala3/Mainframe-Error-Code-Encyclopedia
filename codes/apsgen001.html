MAINFRAME.ENC.PRINT(APSGEN001)

APSGEN001 PSF GENERATOR ERROR

  • E · ERROR
  • PSF
  • Printing and Output Management
Explanation
PSF resource generator detected an error processing a resource.
Likely cause
Page seg/form def/etc. has invalid structured fields.
Programmer response
Recreate the resource using current AFP tools; check version compatibility.
Example
APSGEN001 INVALID PAGE SEGMENT P1IMAGE1 - SF SEQUENCE INVALID
