MAINFRAME.ENC.TXN(DFHFC4701)

DFHFC4701 DEADLOCK ON FILE

  • E · ERROR
  • CICS
  • Transaction Processing and Messaging
Explanation
CICS task was rolled back due to a deadlock on a VSAM file or DB2 connection.
Likely cause
Two transactions held conflicting locks on the same record.
Programmer response
Restart the transaction; tune the application to acquire locks in consistent order.
Example
DFHFC4701 Transaction MYTR rolled back - deadlock on file CUST
