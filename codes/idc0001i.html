MAINFRAME.ENC.STOR(IDC0001I)

IDC0001I FUNCTION COMPLETED WITH MAXIMUM CONDITION CODE

  • I · INFO
  • IDCAMS
  • Storage and Data Sets
Explanation
IDCAMS reports the maximum condition code from the executed commands.
Likely cause
Issued at end of each command and at job end.
Programmer response
Investigate any non-zero condition codes shown.
Example
IDC0001I FUNCTION COMPLETED, HIGHEST CONDITION CODE WAS 0
