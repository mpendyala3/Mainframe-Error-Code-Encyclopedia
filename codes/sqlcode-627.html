MAINFRAME.ENC.DB(-627)

SQLCODE -627 ALTER NOT ALLOWED — DEFAULT STORAGE

  • E · ERROR
  • RESOURCE
  • Databases
Explanation
ALTER TABLESPACE not allowed because no storage attributes were defined.
Likely cause
Tablespace lacks attributes for the requested ALTER.
Programmer response
Specify storage attributes or drop/recreate the TS.
Example
ALTER TABLESPACE TS1 USING STOGROUP SG1;
