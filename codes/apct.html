MAINFRAME.ENC.TXN(APCT)

APCT PROGRAM NOT FOUND

  • E · ERROR
  • CICS ABEND
  • Transaction Processing and Messaging
Explanation
The transaction's initial program could not be loaded.
Likely cause
PROGRAM definition missing in CSD, or PROGRAM not in DFHRPL load library.
Programmer response
CEDA DEFINE PROGRAM(...) GROUP(...) and CEMT NEWCOPY. Verify DFHRPL concatenation in the CICS region JCL.
Example
Transaction MYTR mapped to PGMA, but PGMA not in DFHRPL -> APCT.
