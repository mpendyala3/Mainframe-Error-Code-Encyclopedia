MAINFRAME.ENC.SEC(CSFM015E)

CSFM015E ICSF SERVICE FAILURE

  • E · ERROR
  • ICSF
  • Security and Cryptography
Explanation
A cryptographic API call (encrypt, decrypt, sign) failed.
Likely cause
Key not found, wrong key label, or hardware crypto problem.
Programmer response
Verify key exists with KGUP/csfclr commands; check return/reason in caller.
Example
CSFM015E SERVICE CSNBSAE FAILED - KEY LABEL TEST.AES NOT FOUND
