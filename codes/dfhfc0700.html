MAINFRAME.ENC.TXN(DFHFC0700)

DFHFC0700 FILE OPEN ERROR

  • E · ERROR
  • CICS
  • Transaction Processing and Messaging
Explanation
CICS could not open a file at startup or via CEMT.
Likely cause
Underlying VSAM cluster missing, RACF denied access, or attribute mismatch.
Programmer response
Verify cluster exists with LISTC; check RACF profile for CICS region userid.
Example
DFHFC0700 FILE CUST UNABLE TO OPEN. VSAM rc=8 reason=42
