MAINFRAME.ENC.DB(+462)

SQLCODE +462 EXTERNAL FUNCTION WARNING

  • W · WARNING
  • SYSTEM
  • Databases
Explanation
External function or procedure has returned a warning SQLSTATE.
Likely cause
A UDF or stored procedure invoked from SQL returned a non-zero SQLSTATE starting with '01'.
Programmer response
Inspect the SQLSTATE returned by the routine. Update the routine to clear warnings if expected behavior.
Example
CALL MYPROC(:IN, :OUT);  /* routine returned 01HXX SQLSTATE */
