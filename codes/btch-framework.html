MAINFRAME.ENC.VEND(BTCH FRAMEWORK)

BTCH FRAMEWORK BATCH FRAMEWORK MSG

  • E · ERROR
  • FRAMEWORK
  • Vendor, Business and Custom Applications
Explanation
In-house batch framework issued a controlled-failure message.
Likely cause
Framework detected unrecoverable state — bad checkpoint, parm file error, etc.
Programmer response
Refer to framework manual; restart per recovery procedure.
Example
BTCH-FW: CHECKPOINT FILE CORRUPT - run RECOVER step before retry
