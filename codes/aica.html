MAINFRAME.ENC.TXN(AICA)

AICA RUNAWAY TASK

  • E · ERROR
  • CICS ABEND
  • Transaction Processing and Messaging
Explanation
A transaction exceeded the runaway task time limit and CICS terminated it.
Likely cause
Tight loop in application code or large processing with no CICS service to break the loop.
Programmer response
Locate the loop; add periodic EXEC CICS SUSPEND or other service to give CICS a dispatch point. Tune RUNAWAY value.
Example
DFHAC2206 TRAN APIN ABEND AICA — runaway 5000 ms exceeded
