MAINFRAME.ENC.DB(-102)

SQLCODE -102 STRING CONSTANT IS TOO LONG

  • E · ERROR
  • SYNTAX
  • Databases
Explanation
A string constant or delimited identifier exceeds the maximum length permitted.
Likely cause
Literal longer than 32704 bytes (or 32672 for VARCHAR).
Programmer response
Store the value in a host variable instead of a literal, or split into multiple inserts.
Example
INSERT INTO NOTES VALUES ('A'||'A'||...32K times);
