MAINFRAME.ENC.DB(-604)

SQLCODE -604 INVALID LENGTH/SCALE/SPECIFIED VALUE

  • E · ERROR
  • DATATYPE
  • Databases
Explanation
A length, precision, or scale value is invalid.
Likely cause
Out-of-range values for column data type definition.
Programmer response
Use valid range (e.g., DECIMAL precision 1-31, scale 0..p).
Example
DECIMAL(35,40)
