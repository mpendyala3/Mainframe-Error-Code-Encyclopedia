MAINFRAME.ENC.NET(EZB1052I)

EZB1052I SOCKET BIND FAILED

  • E · ERROR
  • SOCKETS
  • Networking and Communications
Explanation
Application bind() to a socket failed.
Likely cause
Port in use, RACF blocked port, or invalid address.
Programmer response
Use a different port, request RACF SERVAUTH access, or check NETSTAT for owner.
Example
bind(): EZB1052I PORT 80 ALREADY IN USE BY OWNER1
