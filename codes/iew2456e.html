MAINFRAME.ENC.LANG(IEW2456E)

IEW2456E BINDER UNRESOLVED EXTERNAL

  • E · ERROR
  • BINDER
  • Languages, Compilers and Runtimes
Explanation
Linkage editor / binder could not resolve an external reference.
Likely cause
Module references an unresolved CALL, missing LIB INCLUDE, or wrong RES library.
Programmer response
Add INCLUDE for missing module, or correct LIB statement.
Example
IEW2456E SYMBOL MYSUB UNRESOLVED. NO AUTOCALL (NCAL) WAS REQUESTED
