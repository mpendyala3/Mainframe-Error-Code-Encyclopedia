MAINFRAME.ENC.DB(-164)

SQLCODE -164 NOT AUTHORIZED TO CREATE VIEW WITH QUALIFIER

  • E · ERROR
  • AUTHORIZATION
  • Databases
Explanation
User does not have the privilege to create a view with the specified qualifier.
Likely cause
Trying to CREATE VIEW under a schema you don't own without DBADM/SYSADM.
Programmer response
Use your own schema or have SYSADM grant CREATEIN privilege.
Example
CREATE VIEW OTHER.V AS SELECT * FROM EMP;
