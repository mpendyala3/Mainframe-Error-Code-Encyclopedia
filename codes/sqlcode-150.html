MAINFRAME.ENC.DB(-150)

SQLCODE -150 VIEW IS NOT UPDATABLE

  • E · ERROR
  • OBJECT
  • Databases
Explanation
The view named in the INSERT, UPDATE, or DELETE is not defined to allow the requested operation.
Likely cause
View uses DISTINCT, GROUP BY, JOIN, aggregates, or UNION — not updatable.
Programmer response
Update the underlying table directly or use an INSTEAD OF trigger.
Example
UPDATE V_DEPT_SUMMARY SET TOTAL = 100;  /* aggregate view */
