MAINFRAME.ENC.DB(-544)

SQLCODE -544 CHECK CONSTRAINT CANNOT BE ADDED, TABLE CONTAINS A ROW THAT VIOLATES

  • E · ERROR
  • CONSTRAINT
  • Databases
Explanation
An attempt to add a check constraint failed because the table contains rows that violate it.
Likely cause
Existing data fails the new constraint condition.
Programmer response
Clean up data first, or use NOT ENFORCED while you fix, then turn back on.
Example
ALTER TABLE EMP ADD CONSTRAINT C1 CHECK (SAL>0);
