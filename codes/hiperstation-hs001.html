MAINFRAME.ENC.DEV(Hiperstation HS001)

Hiperstation HS001 HIPERSTATION CAPTURE

  • I · INFO
  • HIPERSTATION
  • DevOps, Testing and Debugging
Explanation
Compuware Hiperstation captured a 3270 session for replay/testing.
Likely cause
User initiated capture during interactive testing.
Programmer response
Informational; replay later for regression testing.
Example
HS001 SESSION CAPTURE STARTED - SESSION_ID=SES12345
