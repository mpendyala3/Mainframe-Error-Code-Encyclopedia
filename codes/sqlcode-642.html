MAINFRAME.ENC.DB(-642)

SQLCODE -642 TOO MANY COLUMNS IN A UNIQUE CONSTRAINT

  • E · ERROR
  • RESOURCE
  • Databases
Explanation
Number of columns specified for the UNIQUE constraint exceeds the limit.
Likely cause
UNIQUE has more columns than DB2 allows.
Programmer response
Reduce the number of columns in the constraint.
Example
UNIQUE (C1, C2, ..., C65)
