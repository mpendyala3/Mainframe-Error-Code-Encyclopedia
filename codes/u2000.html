MAINFRAME.ENC.VEND(U2000)

U2000 BATCH PROCESSING ABEND

  • E · ERROR
  • USER ABEND
  • Vendor, Business and Custom Applications
Explanation
Convention used by batch frameworks for unrecoverable processing failures.
Likely cause
Framework detected unrecoverable state; commonly database update failure.
Programmer response
Review framework log files; check restart procedures.
Example
Job abend U2000 - framework log shows DB2 -911 deadlock not retryable
