MAINFRAME.ENC.TXN(MQRC 2009)

MQRC 2009 CONNECTION BROKEN

  • E · ERROR
  • MQ
  • Transaction Processing and Messaging
Explanation
The connection to the queue manager was lost.
Likely cause
Queue manager stopped, network failure, or channel disconnected.
Programmer response
Reconnect via MQCONN. Check qmgr status with DISPLAY QMSTATUS. Review error logs for FDC files.
Example
MQCMIT HCONN, ...
  CompCode=2 Reason=2009 (MQRC_CONNECTION_BROKEN)
